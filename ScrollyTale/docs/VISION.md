# ScrollyTale Vision

ScrollyTale is an inquiry-learning layer built on top of the HKIS Biology Interactive Reader.

The Biology Reader remains the source of truth for:
- chapter content
- simulations
- glossary
- standards
- accessibility features

ScrollyTale owns:
- inquiry sequencing
- pacing
- model capture
- recall
- transfer
- standards evidence

Core loop:

Phenomenon
→ Initial Model
→ Evidence
→ Revision
→ Recall
→ Transfer

The first implementation is Unit 2: The Sealed Garden.
