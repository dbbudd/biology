images/u1/_blocked — DO NOT USE ANY FILE IN THIS FOLDER
=======================================================

Every file here carries a copyright, trademark or provenance problem that makes
it unsafe to publish in the course reader. They are kept only so that nobody
re-extracts them from the source decks believing they are clean. Replace each
one with hand-authored SVG, a properly licensed image, or an interactive.

Where a filename is prefixed `cohen-` the file came from `BIO Cohen 25-26 U1.pptx`;
where it is prefixed `ag1-N-` it came from that Anchor Guide `.docx`; everything
else came from `Bio U1 25-26 Best.pptx`.

REPLACEMENT NOTES
-----------------
As in Unit 5, most of these do not need generated artwork.  The hierarchy of
organisation (image27), the general feedback loop (image115/116), the
thermoregulation loop (image114), the surface-area-to-volume comparison
(image89) and the baroreceptor reflex (image138) are all diagrams — hand-authored
SVG will be cleaner, will recolour across all three themes, and can be made
interactive.  Only the digestive anatomy (image41) is a genuine illustration
problem, and even there a schematic organ-by-organ SVG serves the HS-LS1-2
modelling target better than a photorealistic figure, because the standard
explicitly asks students to model with shapes and arrows rather than draw
anatomically correct diagrams.
